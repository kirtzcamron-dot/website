# website

View the website
----------------

You can view this site in two ways:

- Live (GitHub Pages): https://kirtzcamron-dot.github.io/website

- Locally: run a simple static server from the project root and open http://localhost:8000

	```bash
	# from /home/kirtzcamron/Coding/website
	python3 -m http.server 8000
	```

Notes:
- I assumed the repository is published to GitHub Pages at the URL above (username.github.io/repo). If your Pages site uses a different branch or custom domain, update the link accordingly.
